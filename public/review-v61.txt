## 已完成

- 旧便笺独立恢复，返回开场不会重置手动草稿；不会把历史收件静默改成默认消息。

1. 新版真实 HTML/控制器的 Node DOM 模型：23 组检查通过。覆盖四个逻辑状态、无全景结构、默认候选独立、类别推荐、超限/空包拒绝、编辑校验、回看草稿保留、旧版本收件、独立快照、存储失败、键盘、减少动态效果、首次揭示、快速切页、焦点与分页阅读锚点、文字下载和清除失败。
2. 49 项编码、分页、动效及历史回归测试通过。其中包括旧包兼容、新分类包和历史系统状态回归，历史系统状态不代表当前入口仍包含全景。
3. 独立源码审查发现首屏隐藏头尾后 CSS Grid 可能把内容放到零高行，且切换时舞台收缩会使离场文字跳动。已改为所有章节共用固定的全屏舞台，导航和页脚叠放，后续操作页自行预留对应空间。短屏字级与按钮空间按视口约束复核。
4. 本地启动器及导出工具的离线检查覆盖路径解析、MIME、静态响应、白名单与 ZIP 完整性；未启动预览服务器或声称实机运行验证。

## 本地交付

导出 ZIP 包含可直接修改的静态源码与素材，以及中文 README、Windows 双击启动脚本、Python/Node 静态文件启动器。无需 npm install、数据库、账号或密钥。

完整解压后，Windows 双击 start-local.bat。也可在根目录运行 npm start（Node.js 18+）或 py -3 serve.py（Python 3.8+）。浏览器访问 http://127.0.0.1:8080。服务仅监听本机，用于提供静态文件，不进行消息通信。

不要直接双击 index.html：本页使用 JavaScript 模块，需要 HTTP 环境。编辑 public/index.html、样式或模块后刷新即可，不需要构建。

部署到其它静态托管时，上传 public 内全部文件。导出包不含托管身份、Git 历史、凭据、node_modules 或历史后端。
